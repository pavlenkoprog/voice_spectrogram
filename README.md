# Анализатор голосовых файлов

Программа для анализа голосовых файлов с визуализацией спектрограммы и графика громкости.

## Описание

Программа позволяет загружать WAV файлы, настраивать параметры анализа и визуализировать:
- **Спектрограмму** - частотно-временное представление сигнала
- **График громкости** - огибающую амплитуды сигнала во времени

## Методика получения спектрограммы

### Кратковременное преобразование Фурье (STFT)

Спектрограмма получается путем применения кратковременного преобразования Фурье (Short-Time Fourier Transform, STFT) к аудиосигналу. STFT представляет собой метод анализа сигналов, который расширяет классическое преобразование Фурье для анализа сигналов, частотные характеристики которых изменяются во времени.

#### Принцип работы STFT

Классическое преобразование Фурье (FFT) анализирует весь сигнал целиком и дает только частотную информацию, показывая, какие частоты присутствуют в сигнале, но не указывая, когда именно эти частоты возникают. Это подходит для стационарных сигналов - сигналов, частотный состав которых остается постоянным на протяжении всего времени анализа. Примером стационарного сигнала может служить чистый тон (синусоида) постоянной частоты или белый шум с постоянными статистическими характеристиками.

Однако большинство реальных аудиосигналов, таких как речь, музыка или звуки окружающей среды, являются нестационарными - их частотный состав изменяется во времени. Например, при произнесении слова "привет" сначала возникают частоты, характерные для звука "п", затем для "р", "и", "в", "е", "т" - каждый звук имеет свой уникальный частотный состав. Классическое FFT, примененное ко всему слову, покажет все эти частоты одновременно, но не даст информации о том, в какой момент времени каждая частота присутствовала в сигнале.

STFT решает эту проблему путем разбиения сигнала на короткие временные сегменты, называемые окнами, и применения обычного FFT к каждому сегменту отдельно. По сути, STFT - это последовательное применение FFT к скользящим окнам сигнала. В результате получается двумерное представление сигнала, где одна ось соответствует времени, а другая - частоте, а значения в каждой точке отражают амплитуду (или мощность) соответствующей частотной компоненты в данный момент времени. Таким образом, STFT позволяет отслеживать, как частотный состав сигнала изменяется во времени, что критически важно для анализа речевых и музыкальных сигналов.

Процесс вычисления STFT можно представить следующим образом. Исходный аудиосигнал последовательно "просматривается" скользящим окном фиксированной длины. На каждом шаге окно выделяет определенный временной сегмент сигнала. К этому сегменту применяется оконная функция, которая плавно затухает к краям сегмента, что необходимо для уменьшения артефактов на границах. Затем к обработанному сегменту применяется дискретное преобразование Фурье, которое раскладывает сигнал на его частотные компоненты. Результат преобразования Фурье для каждого сегмента представляет собой комплексный спектр, содержащий информацию об амплитуде и фазе каждой частотной компоненты в данном временном окне. После этого окно сдвигается на некоторое расстояние по временной оси, и процесс повторяется для следующего сегмента. Величина сдвига определяет временное разрешение спектрограммы - чем меньше сдвиг, тем выше временное разрешение, но тем больше вычислительных операций требуется.

#### Проблема компромисса между частотным и временным разрешением

Одной из ключевых особенностей STFT является фундаментальный компромисс между частотным и временным разрешением, известный как принцип неопределенности Гейзенберга в обработке сигналов. Частотное разрешение определяет способность различать близко расположенные частотные компоненты, а временное разрешение - способность точно локализовать изменения сигнала во времени. Эти два параметра взаимосвязаны обратной зависимостью: улучшение одного неизбежно приводит к ухудшению другого.

Размер окна является основным параметром, определяющим этот компромисс. Большое окно содержит больше отсчетов сигнала, что при преобразовании Фурье дает больше частотных бинов и, соответственно, лучшее частотное разрешение. Однако большое окно также означает, что спектральная характеристика усредняется по более длительному временному интервалу, что ухудшает способность отслеживать быстрые изменения сигнала во времени. Напротив, малое окно обеспечивает хорошее временное разрешение, позволяя точно фиксировать моменты изменения характеристик сигнала, но при этом частотное разрешение ухудшается, так как для анализа доступно меньше данных.

Частотное разрешение напрямую связано с размером окна через соотношение, согласно которому разрешение по частоте равно частоте дискретизации, деленной на размер окна. Это означает, что при фиксированной частоте дискретизации увеличение размера окна в два раза улучшает частотное разрешение в два раза, но одновременно ухудшает временное разрешение. Временное разрешение, в свою очередь, определяется длительностью окна во времени, которая равна размеру окна, деленному на частоту дискретизации. Таким образом, выбор размера окна представляет собой балансирование между необходимостью различать близкие частоты и необходимостью точно локализовать события во времени.

Для речевых сигналов, где важны как формантные частоты (требующие хорошего частотного разрешения), так и моменты начала и окончания звуков (требующие хорошего временного разрешения), обычно выбирают средние значения размера окна, обеспечивающие приемлемый компромисс. Для музыкальных сигналов, где важны гармонические соотношения, часто предпочтительны большие окна для лучшего частотного разрешения. Для сигналов с быстрыми изменениями, таких как ударные инструменты или согласные звуки, используют меньшие окна для сохранения временной детализации.

#### Оконные функции и спектральная утечка

Применение оконных функций является критически важным аспектом STFT, необходимым для уменьшения эффекта спектральной утечки. Спектральная утечка возникает из-за того, что при выделении конечного сегмента сигнала происходит его неявное умножение на прямоугольное окно, которое имеет резкие переходы на границах. В частотной области это приводит к появлению артефактов в виде боковых лепестков - ложных частотных компонентов, которые маскируют реальные частотные характеристики сигнала. Оконные функции решают эту проблему путем плавного затухания сигнала к краям сегмента, что существенно уменьшает уровень боковых лепестков в частотном представлении.

Окно Ханна, также известное как окно Ханнинга, является одним из наиболее популярных выборов для анализа сигналов. Оно обеспечивает плавное затухание от центра к краям по косинусоидальному закону, что дает хороший баланс между шириной главного лепестка в частотной области и уровнем подавления боковых лепестков. Главный лепесток определяет частотное разрешение - его ширина обратно пропорциональна размеру окна. Боковые лепестки представляют собой нежелательные артефакты, которые могут создавать ложные частотные компоненты. Окно Ханна обеспечивает подавление боковых лепестков примерно на 32 децибела относительно главного лепестка, что для большинства практических применений является достаточным.

Окно Хэмминга является модификацией окна Ханна с несколько иными коэффициентами. Оно обеспечивает более узкий главный лепесток, что теоретически улучшает частотное разрешение, но при этом уровень боковых лепестков остается примерно на том же уровне, что и у окна Ханна. Различия между этими окнами в практических применениях обычно незначительны, и выбор между ними часто определяется традициями в конкретной области применения.

Окно Блэкмана обеспечивает максимальное подавление боковых лепестков среди стандартных оконных функций - до 58 децибел. Это достигается за счет использования более сложной функции затухания, включающей несколько гармонических компонентов. Однако такое улучшение подавления боковых лепестков достигается ценой расширения главного лепестка, что ухудшает частотное разрешение. Окно Блэкмана особенно полезно в случаях, когда необходимо анализировать слабые частотные компоненты в присутствии сильных, так как оно лучше подавляет артефакты от сильных компонентов.

Окно Бартлетта, также называемое треугольным окном, обеспечивает линейное затухание от центра к краям. Оно представляет собой компромиссный вариант между прямоугольным окном и более сложными окнами типа Ханна. Его характеристики по подавлению боковых лепестков и ширине главного лепестка находятся между характеристиками прямоугольного окна и окна Ханна. В современных приложениях оно используется реже, чем окна Ханна или Хэмминга.

Прямоугольное окно, также называемое окном Бокскара, представляет собой простейший случай - оно не изменяет сигнал внутри сегмента, оставляя его значения неизменными до самых краев, где происходит резкий обрыв. Хотя прямоугольное окно обеспечивает максимально узкий главный лепесток и, следовательно, лучшее теоретическое частотное разрешение, оно создает очень высокий уровень боковых лепестков - до 13 децибел для первого бокового лепестка. Это приводит к сильной спектральной утечке, которая может полностью маскировать слабые частотные компоненты. Прямоугольное окно используется редко, в основном в случаях, когда важна максимальная частотная детализация и можно пренебречь артефактами спектральной утечки.

Выбор оконной функции представляет собой балансирование между несколькими факторами. Узкий главный лепесток обеспечивает лучшее частотное разрешение, позволяя различать близко расположенные частотные компоненты. Низкий уровень боковых лепестков уменьшает артефакты и позволяет обнаруживать слабые сигналы в присутствии сильных. Для большинства практических применений в анализе речевых и музыкальных сигналов окно Ханна обеспечивает оптимальный компромисс между этими требованиями, что делает его стандартным выбором по умолчанию во многих системах анализа сигналов.

#### Параметры STFT и их влияние на качество анализа

**Размер окна (nperseg):**

Размер окна является наиболее критическим параметром STFT, определяющим фундаментальный компромисс между частотным и временным разрешением. Этот параметр задает количество отсчетов сигнала, которые анализируются в каждом временном сегменте. При выборе размера окна необходимо учитывать характер анализируемого сигнала и цели анализа.

Для сигналов с медленно изменяющимися частотными характеристиками, таких как устойчивые музыкальные тоны или гласные звуки в речи, предпочтительны большие окна. Большое окно обеспечивает высокое частотное разрешение, позволяя точно определять частоты формант в речи или гармоник в музыке. Однако при этом временное разрешение ухудшается, что может привести к размытию быстрых переходов между звуками. В практических применениях для таких сигналов часто используют окна размером 2048 или 4096 отсчетов, что при типичной частоте дискретизации 44100 Гц дает временное разрешение порядка 46-93 миллисекунд.

Для сигналов с быстрыми изменениями, таких как согласные звуки в речи, ударные инструменты или переходные процессы, необходимы малые окна для сохранения временной детализации. Малое окно позволяет точно фиксировать моменты начала и окончания звуков, но при этом частотное разрешение снижается, что может затруднить точное определение частотных характеристик. Для таких применений обычно используют окна размером 256 или 512 отсчетов, обеспечивающие временное разрешение порядка 6-12 миллисекунд.

Универсальным выбором для большинства приложений является размер окна 1024 отсчета, который обеспечивает приемлемый баланс между частотным и временным разрешением. При частоте дискретизации 44100 Гц это дает частотное разрешение около 43 Гц и временное разрешение около 23 миллисекунд, что подходит для анализа большинства речевых и музыкальных сигналов.

Важным практическим соображением является использование размеров окон, равных степеням двойки. Это связано с тем, что алгоритм быстрого преобразования Фурье (FFT), используемый для вычисления дискретного преобразования Фурье, наиболее эффективен именно для таких размеров. FFT для размера, равного степени двойки, имеет вычислительную сложность порядка N log N, где N - размер окна, в то время как для произвольных размеров сложность может быть значительно выше. Поэтому стандартными значениями являются 256, 512, 1024, 2048, 4096 и 8192 отсчетов.

**Перекрытие окон (noverlap):**

Перекрытие окон определяет, какая часть данных используется повторно при переходе от одного временного сегмента к следующему. Этот параметр критически влияет на качество временной локализации в спектрограмме и на плавность визуального представления результатов.

При нулевом перекрытии каждое окно анализирует совершенно новый сегмент сигнала, не имеющий общих данных с предыдущим окном. Это обеспечивает максимальную скорость вычислений, так как обрабатывается минимальное количество данных. Однако при этом временное разрешение ограничивается длительностью окна, и быстрые изменения сигнала могут быть пропущены, если они происходят между окнами. Кроме того, спектрограмма может выглядеть дискретной и менее плавной.

Высокое перекрытие, составляющее 80-95 процентов от размера окна, означает, что соседние окна имеют значительную область общих данных. Это существенно улучшает временное разрешение спектрограммы, так как изменения сигнала отслеживаются с шагом, намного меньшим, чем длительность окна. Например, при размере окна 1024 отсчета и перекрытии 90 процентов шаг между окнами составляет всего 102 отсчета, что при частоте дискретизации 44100 Гц дает временное разрешение около 2.3 миллисекунды вместо 23 миллисекунд при нулевом перекрытии.

Высокое перекрытие также обеспечивает более плавную и непрерывную визуализацию спектрограммы, так как соседние временные кадры имеют общие данные и их спектральные характеристики изменяются плавно. Это особенно важно для визуального анализа, где резкие скачки между кадрами могут создавать артефакты и затруднять интерпретацию результатов.

Однако высокое перекрытие имеет существенный недостаток - оно значительно увеличивает объем вычислений. При перекрытии 90 процентов количество обрабатываемых временных кадров увеличивается примерно в 10 раз по сравнению с нулевым перекрытием. Это означает, что время вычисления спектрограммы также увеличивается примерно в 10 раз. Для больших аудиофайлов это может стать критическим фактором производительности.

Средние значения перекрытия, составляющие 50-75 процентов, представляют компромисс между качеством анализа и вычислительной эффективностью. Они обеспечивают приемлемое временное разрешение и плавность спектрограммы при умеренном увеличении вычислительной нагрузки.

В практических применениях выбор перекрытия зависит от конкретных требований. Для предварительного анализа или работы с большими файлами может быть достаточно перекрытия 50-70 процентов. Для детального анализа, особенно когда важна точная временная локализация событий, рекомендуется использовать перекрытие 85-95 процентов. Для большинства стандартных задач оптимальным является перекрытие около 75-90 процентов, обеспечивающее хороший баланс между качеством и производительностью.

#### Спектральное представление и обработка результатов

После применения преобразования Фурье к каждому временному сегменту получается комплексная спектрограмма, содержащая информацию как об амплитуде, так и о фазе каждой частотной компоненты. Комплексное представление необходимо для полного описания сигнала, но для большинства задач визуализации и анализа используется только амплитудная информация, извлекаемая путем вычисления модуля комплексного числа.

Амплитудный спектр представляет собой наиболее информативное представление для визуального анализа, так как он отражает относительную интенсивность различных частотных компонент в каждый момент времени. Вычисление амплитудного спектра выполняется путем извлечения квадратного корня из суммы квадратов действительной и мнимой частей комплексного спектра. Это значение показывает, насколько сильна каждая частотная компонента, независимо от ее фазы.

Спектральная плотность мощности является альтернативным представлением, которое фокусируется на энергетических характеристиках сигнала. Она вычисляется как квадрат амплитудного спектра, нормализованный на частоту дискретизации и размер окна. Это представление особенно полезно для энергетического анализа и для задач, где важна мощность сигнала в различных частотных диапазонах. Спектральная плотность мощности имеет физический смысл и измеряется в единицах мощности на единицу частоты, что делает ее удобной для количественного анализа.

Логарифмическое представление в децибелах является стандартным способом визуализации спектрограмм по нескольким причинам. Во-первых, амплитуды сигналов в аудиоприложениях могут варьировать на несколько порядков величины - от очень тихих до очень громких компонент. Линейное представление не позволяет одновременно визуализировать такие разные по величине компоненты, так как слабые сигналы будут практически невидимы на фоне сильных. Логарифмическое масштабирование сжимает динамический диапазон, делая видимыми как сильные, так и слабые компоненты.

Во-вторых, человеческое восприятие громкости также является логарифмическим, поэтому представление в децибелах более естественно соответствует нашему восприятию звука. Переход к децибелам выполняется путем умножения десятичного логарифма амплитуды на двадцать, что связано с тем, что мощность пропорциональна квадрату амплитуды, а децибелы для мощности вычисляются с коэффициентом десять.

Для предотвращения проблем с вычислением логарифма от нулевых или очень малых значений используется добавление малой константы перед вычислением логарифма. Это гарантирует, что даже тихие компоненты будут иметь конечное значение в децибелах, хотя и очень отрицательное.

Ограничение динамического диапазона путем обрезки значений децибел до заданного диапазона является важным шагом для улучшения визуализации. Без такого ограничения спектрограмма может содержать значения от очень отрицательных децибел (соответствующих шуму или артефактам) до нуля децибел (максимальная амплитуда). Такой широкий диапазон затрудняет визуальное восприятие, так как большая часть цветовой шкалы будет использоваться для отображения неинформативных очень тихих компонент. Ограничение диапазона позволяет сфокусировать визуализацию на информативных компонентах сигнала, улучшая контрастность и читаемость спектрограммы.

#### Масштабирование и нормализация

Выбор типа масштабирования спектра имеет важное значение для корректного количественного анализа и сравнения результатов, полученных с разными параметрами. Спектральная плотность является предпочтительным выбором для большинства приложений, так как она обеспечивает корректную нормализацию результатов относительно размера окна и частоты дискретизации.

При использовании спектральной плотности результаты масштабируются с учетом энергии оконной функции и параметров анализа. Это означает, что спектрограммы, полученные с разными размерами окон, можно корректно сравнивать между собой, так как различия, связанные с размером окна, компенсируются нормализацией. Это особенно важно при сравнительном анализе, когда необходимо оценить, как изменение параметров влияет на результаты, исключив артефакты, связанные с масштабированием.

Спектр мощности представляет собой более простое представление, которое не учитывает нормализацию относительно размера окна. Это означает, что при изменении размера окна значения в спектрограмме будут изменяться не только из-за реальных различий в сигнале, но и из-за различий в масштабировании. Поэтому спектр мощности используется реже и в основном в случаях, когда необходимо сохранить абсолютные значения мощности без нормализации.

Выбор между этими двумя типами масштабирования зависит от целей анализа. Для качественной визуализации и общего анализа обычно достаточно спектральной плотности. Для количественного анализа, особенно когда необходимо сравнивать результаты, полученные с разными параметрами, спектральная плотность является обязательным выбором.

### Методика получения огибающей громкости

Огибающая громкости (amplitude envelope) получается следующим образом:

1. **Нормализация сигнала:**
   ```
   x_norm[n] = x[n] / max(|x[n]|)
   ```

2. **Вычисление модуля:**
   ```
   |x_norm[n]| = |x_norm[n]|
   ```

3. **Сглаживание скользящим средним:**
   ```
   envelope[n] = (1/M) · Σ_{m=0}^{M-1} |x_norm[n - m]|
   ```
   
   где M - размер окна сглаживания:
   ```
   M = fs · (smooth_window_ms / 1000)
   ```

Размер окна сглаживания определяет баланс между детализацией и плавностью огибающей. Малые значения (1-5 мс) сохраняют быстрые изменения, большие значения (10-50 мс) дают более плавную кривую.

## Параметры анализа и их влияние

### Временные параметры

#### Начало времени (t_start)
- **Единицы измерения:** секунды
- **Диапазон:** 0 ≤ t_start < t_end
- **Влияние на анализ:** Определяет начальную точку временного сегмента для анализа. Влияет на выбор анализируемого фрагмента сигнала и отображаемый временной диапазон на графиках.

#### Конец времени (t_end)
- **Единицы измерения:** секунды
- **Диапазон:** t_start < t_end ≤ длительность_файла
- **Влияние на анализ:** Определяет конечную точку временного сегмента. Вместе с t_start задает анализируемый фрагмент аудио. Длина сегмента (t_end - t_start) влияет на количество данных, обрабатываемых за один раз.

### Параметры окна STFT

#### Размер окна (nperseg)
- **Единицы измерения:** количество отсчетов
- **Диапазон:** положительные целые числа, рекомендуется степени двойки
- **Влияние на разрешение:**
  - **Частотное разрешение:** Δf = fs / nperseg (обратно пропорционально)
  - **Временное разрешение:** Δt = nperseg / fs (прямо пропорционально)
- **Рекомендации:**
  - **256-512:** для сигналов с быстрыми изменениями (требуется хорошее временное разрешение)
  - **1024-2048:** универсальный выбор для большинства задач
  - **4096-8192:** для детального частотного анализа (требуется хорошее частотное разрешение)

#### Функция окна (window)
- **Тип:** выбор из набора оконных функций
- **Влияние на спектральные характеристики:**
  - **Hann:** оптимальный баланс между шириной главного лепестка и уровнем боковых лепестков (-32 дБ)
  - **Hamming:** более узкий главный лепесток, но выше уровень боковых лепестков (-43 дБ)
  - **Blackman:** максимальное подавление боковых лепестков (-58 дБ), но широкий главный лепесток
  - **Bartlett:** треугольное окно, средние характеристики
  - **Boxcar:** прямоугольное окно, максимальное разрешение, но сильная спектральная утечка

#### Перекрытие (noverlap_percent)
- **Единицы измерения:** проценты
- **Диапазон:** 0-99%
- **Влияние на качество спектрограммы:**
  - **Высокое перекрытие (80-95%):**
    - Улучшенное временное разрешение
    - Более плавная визуализация
    - Увеличенное время вычислений (квадратичная зависимость)
  - **Низкое перекрытие (0-50%):**
    - Быстрее вычисления
    - Возможна потеря информации о быстрых изменениях
    - Менее плавная спектрограмма
- **Оптимальное значение:** 75-90% для большинства приложений

### Параметры частотного диапазона

#### Максимальная частота (freq_limit)
- **Единицы измерения:** Герцы (Гц)
- **Диапазон:** 0 < freq_limit ≤ fs/2 (теорема Найквиста)
- **Влияние на анализ:**
  - Ограничивает частотный диапазон для визуализации
  - Позволяет фокусироваться на определенном частотном диапазоне
  - Уменьшает объем данных для обработки
- **Рекомендации по применению:**
  - **Речь:** 0-8000 Гц (основной диапазон речевых формант)
  - **Музыка:** 0-20000 Гц (полный слышимый диапазон)
  - **Низкочастотный анализ:** 0-1000 Гц (фундаментальные частоты)

### Параметры спектрального представления

#### Режим (mode)
- **Варианты:** magnitude, psd, phase, angle, complex
- **Влияние на интерпретацию результатов:**
  - **magnitude:** амплитудный спектр, наиболее информативен для визуализации
  - **psd:** спектральная плотность мощности, используется для энергетического анализа
  - **phase/angle:** фазовый спектр, важен для анализа временных характеристик
  - **complex:** полное комплексное представление

#### Масштабирование (scaling)
- **Варианты:** density, spectrum
- **Влияние на количественные характеристики:**
  - **density:** нормализованная спектральная плотность, позволяет корректно сравнивать результаты с разными параметрами окна
  - **spectrum:** спектр мощности, зависит от размера окна

### Параметры визуализации

#### Минимальный уровень дБ (db_min)
- **Единицы измерения:** децибелы (дБ)
- **Диапазон:** < db_max
- **Влияние на визуализацию:**
  - Определяет нижний порог динамического диапазона
  - Более низкие значения (-70, -80 дБ) показывают больше деталей в тихих компонентах сигнала
  - Более высокие значения (-30, -40 дБ) скрывают шум и фокусируются на сильных сигналах
  - Влияет на контрастность и читаемость спектрограммы

#### Максимальный уровень дБ (db_max)
- **Единицы измерения:** децибелы (дБ)
- **Диапазон:** > db_min
- **Влияние на визуализацию:**
  - Определяет верхний порог динамического диапазона
  - Обычно устанавливается в 0 дБ (максимальная амплитуда в сигнале)
  - Вместе с db_min задает динамический диапазон: DR = db_max - db_min
  - Больший диапазон улучшает визуализацию слабых компонентов

### Внутренние параметры

#### Сглаживание (shading)
- **Значение:** gouraud
- **Описание:** Метод интерполяции цветов между узлами сетки спектрограммы
- **Влияние:** Обеспечивает плавные цветовые переходы, улучшая визуальное восприятие

#### Цветовая карта (cmap)
- **Значение:** inferno
- **Описание:** Цветовая схема для отображения амплитуд
- **Влияние:** Определяет соответствие между значениями амплитуды и цветом. Влияет на восприятие и интерпретацию спектрограммы

#### Сглаживание громкости (smooth_window)
- **Единицы измерения:** миллисекунды
- **Значение:** 5 мс
- **Влияние на огибающую:**
  - Малые значения (1-5 мс): сохраняют быстрые изменения амплитуды
  - Большие значения (10-50 мс): дают более плавную огибающую, скрывая быстрые флуктуации

## Валидация параметров

Программа автоматически проверяет корректность введенных значений:

- **Временные параметры:** проверяется логическая корректность (t_start < t_end, t_end ≤ длительность файла)
- **Числовые поля:** принимают только числовые значения соответствующего типа
- **Проценты:** ограничены диапазоном 0-99%
- **Диапазон дБ:** проверяется условие db_min < db_max
- **Автоматическая коррекция:** значения автоматически корректируются при выходе за допустимые границы

## Примеры применения методики

### Анализ речевых сигналов

Для анализа речевых сигналов рекомендуется следующая конфигурация:
- **Размер окна:** 1024-2048 отсчетов (частотное разрешение ~8-16 Гц при fs=16000 Гц)
- **Оконная функция:** Hann (оптимальный баланс)
- **Перекрытие:** 90% (высокое временное разрешение для анализа формант)
- **Максимальная частота:** 8000 Гц (основной диапазон речевых формант)
- **Диапазон дБ:** -50 до 0 дБ

### Анализ музыкальных сигналов

Для анализа музыкальных сигналов:
- **Размер окна:** 2048-4096 отсчетов (лучшее частотное разрешение для гармоник)
- **Оконная функция:** Hann или Blackman (подавление артефактов)
- **Перекрытие:** 90-95%
- **Максимальная частота:** 20000 Гц (полный слышимый диапазон)
- **Диапазон дБ:** -60 до 0 дБ (больший динамический диапазон)

### Детальный спектральный анализ

Для максимальной детализации:
- **Размер окна:** 4096-8192 отсчетов
- **Оконная функция:** Blackman (максимальное подавление утечки)
- **Перекрытие:** 95%
- **Максимальная частота:** 20000 Гц
- **Диапазон дБ:** -70 до 0 дБ
